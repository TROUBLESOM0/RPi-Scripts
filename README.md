 Cron scripts are stored at ~/.config/cronscripts

 After creating script, (from ~/scripts/)
 1.  chmod to rwx "chmod u+rwx,g+rwx,o+r [filename]"
 2.  then,  "sudo ln -s [FULL file path] (/bin/[name-to-type-in-terminal])"
